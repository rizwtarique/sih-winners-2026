## 🐝 About

**Honey Chain** is a smart beekeeping and honey traceability platform that creates a transparent digital connection between the **hive, beekeeper, harvest, honey batch, quality records, supply chain, and consumer**.

It combines:

| | |
|---|---|
| 📡 | IoT-based hive telemetry |
| 🔗 | Blockchain-backed provenance |
| 📱 | QR-based consumer verification |
| 🧪 | Laboratory quality records |
| 🤖 | AI/ML analytics for hive health & productivity |
| 📊 | Beekeeper & administrative dashboards |
| 🛡️ | Tamper-evident record integrity |

> **Every honey batch should have a digital story that can be traced, verified, and understood.**

---

## 🎯 Problem Statement

Built for **Smart India Hackathon 2026** — Problem Statement `SIH26021`.

Honey Chain addresses:

- Lack of honey traceability and consumer trust
- Manual, paper-based beekeeper record keeping
- No standardized digital quality documentation
- Limited visibility into hive health and productivity
- Fragmented supply-chain transparency

## ✨ Features

<details>
<summary><strong>🐝 Smart Beekeeper Dashboard</strong></summary>

Centralized workspace for beekeepers — apiary & hive management, harvest records, honey batches, live telemetry, alerts, traceability, QR verification, and analytics.
</details>

<details>
<summary><strong>🍯 Honey Batch Traceability</strong></summary>

Every batch gets a unique digital identity that moves through a defined lifecycle:

```
HARVESTED → EXTRACTED → PROCESSED → TESTED → PACKAGED → VERIFIED
```

**Example record**

| Field | Value |
|---|---|
| Batch ID | `HC-2026-0101` |
| Hive | `HIVE-042` |
| Apiary | North Valley Apiary |
| Honey Type | Wild Mustard |
| Harvest Date | 22 September 2026 |
| Quantity | 22 kg |

</details>

<details>
<summary><strong>📱 QR Consumer Verification</strong></summary>

Consumers scan a QR code on the jar and instantly view the batch's beekeeper, apiary, hive, harvest date, processing history, quality data, and blockchain integrity status — with zero blockchain knowledge required.
</details>

<details>
<summary><strong>🧪 Laboratory Quality Records</strong></summary>

Batches can be linked to lab data — analyst, test date, moisture, HMF, adulteration indicators, and certificate references. Scientific evidence is kept clearly separate from blockchain integrity: **blockchain proves record integrity, not honey purity.**
</details>

<details>
<summary><strong>🔗 Blockchain Provenance</strong></summary>

A lightweight integrity layer anchors cryptographic commitments of key traceability events — batch ID, event type, document hash, timestamp, and transaction reference — while bulk application data stays off-chain in PostgreSQL for scalability.
</details>

<details>
<summary><strong>🛡️ Tamper Detection</strong></summary>

Every committed record is hashed. Re-hashing and comparing against the original commitment instantly surfaces silent modification of stored data.
</details>

<details>
<summary><strong>📡 Smart Hive Monitoring</strong></summary>

Designed for IoT-enabled tracking of temperature, humidity, hive weight, and acoustic activity via ESP32 → MQTT/HTTP → backend. The current build uses simulated telemetry so the UI/UX isn't blocked on hardware.
</details>

<details>
<summary><strong>🤖 AI / ML Insights</strong></summary>

Planned models turn sensor + historical data into **colony health/risk scores**, **disease-risk flags**, and **productivity predictions** — treated as decision-support estimates, not certified results.
</details>

                 ▼               ▼               ▼
            PostgreSQL         AI / ML       Blockchain

**Platform roles:** Beekeeper · Laboratory · Administrator · Consumer — each with a scoped dashboard and permission set.

## ⚙️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS)
- npm (or bun — `bun.lock` is present)
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/rizwtarique/sih-winners-2026.git
cd sih-winners-2026

# Install dependencies
npm install

# Configure environment
cp .env.example .env

# Start the dev server
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## 🔐 Security Principles

- Never commit secrets or hardcode API keys
- Never expose private blockchain keys
- Passwords are never stored in plaintext
- All user input is validated; protected operations are authenticated and authorized by role
- Sensitive personal data and large sensor datasets are kept **off-chain**
- Internal errors are never exposed to end users
- Important actions remain auditable

## ⚠️ Prototype Status

Honey Chain is an **evolving prototype**. Some components are intentionally simulated for demonstration purposes.

| | Current | Target |
|---|---|---|
| Frontend | React (mock data) | React / Next.js + FastAPI |
| IoT | Simulated | ESP32 + real sensors |
| Blockchain | Prototype flow | Deployed smart contracts |
| AI/ML | Not yet validated | Trained on real datasets |

Simulated data, blockchain values, or AI results are never presented as real-world scientific validation.

---

## 📜 Disclaimer

Honey Chain is a **student / hackathon prototype** built for educational, research, and demonstration purposes.

- Blockchain records provide integrity and provenance for *submitted* information — they do not independently establish the purity, authenticity, safety, or scientific quality of honey.
- AI/ML outputs are decision-support estimates unless validated against real-world datasets and domain expertise.
